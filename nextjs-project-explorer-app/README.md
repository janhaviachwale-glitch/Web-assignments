# Project Explorer

Project Explorer is a Next.js app for managing and exploring project work in one workspace. It includes a landing page, dashboard, searchable project listings, project detail pages, and supporting workspace sections for navigation.

## Features implemented

- Home page with workspace overview and navigation cards
- About page describing the project management workspace
- Dashboard overview with summary statistics
- Projects page with:
  - search by name, description, or category
  - status filter
  - count of visible projects
  - project progress cards and detail links
- Project detail page for each project, including:
  - progress tracking
  - due date
  - team member list
  - project status
- Nested project tabs for Overview, Team, Tasks, and Activity
- Settings page for workspace configuration
- Dashboard subpages for Team and Activity
- Responsive styling for desktop and mobile layouts

## Tech stack

- Next.js
- React
- TypeScript
- CSS modules via global stylesheet

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in the browser.
